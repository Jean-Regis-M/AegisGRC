# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.2.x   | Yes       |
| 1.1.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

We request that you report vulnerabilities privately rather than creating public GitHub Issues. 

1. Email GRC security maintainers at **security@aegisgrc.enterprise** with details of the flaw and a proof of concept.
2. We strive to acknowledge reports within 48 hours and provide a coordinated remediation path within 14 business days.
3. Once fixed, CVE identifiers are requested and credit is formally allocated.
