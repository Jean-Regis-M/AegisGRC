# AegisGRC Security Policy

We treat platform safety and trust-boundaries with maximum engineering care.

---

## 1. Supported Versions

| Version | Status | Security Support |
| :--- | :--- | :--- |
| **v1.x.x** | Current Production | Fully Supported |

---

## 2. Reporting an Issue

If you spot a credentials exposure risk or vulnerability in AegisGRC:
1. Do **not** log a public Github issue.
2. Email your findings confidentially to `security@aegisgrc.org`.
3. Give our security team 48 hours to research and deploy patches before disclosing details.
